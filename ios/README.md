# iOS

The native iOS application is a future portfolio milestone. The Android FocusLab bootstrap intentionally leaves this directory documentation-only so the first change stays focused and reviewable.

The proposed iOS baseline is SwiftUI with MVVM, Xcode 27.2, the bundled Swift 6.4 toolchain, and iOS 17 or later. Versions will be revalidated against Apple's stable toolchain when implementation begins.
